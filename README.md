# Алгоритмы и структуры данных

Учебный проект: **WPF-приложение** с графической визуализацией восьми практических работ и **консольный лаунчер** для быстрого запуска решений, автотестов и истории.

## Состав проекта

| Папка | Назначение |
|---|---|
| `AlghoritmsAndDataStructures/` | WPF-приложение (MVVM, CommunityToolkit): окна решений и 3D/2D-визуализации |
| `AlgorithmsLauncher/` | Консольный лаунчер (компактный CLI, без зависимостей WPF) |
| `AlghoritmsAndDataStructures/Core/Calculators/` | Общая логика вычислений (файлы подключаются в оба проекта как link) |
| `installer/setup.iss` | Скрипт Inno Setup (сборка `setup.exe`) |

## Практические работы

1. Куб (площадь грани, полная поверхность, объём), дробь M/N (цифры целой и дробной части)
2. Функция, заданная графиком (параметр R)
3. Попадание точки в заштрихованную область
4. Сумма ряда Σ k/(k+1) и среднее арифметическое трёхзначных чисел
5. Массив: среднее на нечётных позициях, замена кратных 3
6. Сумма ряда e⁻ˣ с заданной точностью
7. Быстрая сортировка по убыванию
8. Замена элемента средним арифметическим соседей

## Сборка

Требуется Visual Studio 2022 (.NET Framework 4.8, WPF) + NuGet (пакеты восстанавливаются из `packages/`).

```
MSBuild.exe AlghoritmsAndDataStructures.sln /tv:Current /t:Build /p:Configuration=Release /v:m
```

Отдельно консольный лаунчер:

```
MSBuild.exe AlgorithmsLauncher\AlgorithmsLauncher.csproj /tv:Current /t:Build /p:Configuration=Release /v:m
```

## Запуск

Для полного отображения (рамки, эмодзи, анимации) запускайте лаунчер **из Windows Terminal** —
в классическом `cmd`/conhost автоматически включается упрощённый ASCII-вариант.

`AlgorithmsLauncher.exe`:
- `1` — запустить графическую версию (WPF)
- `2` — решения задач в консоли (ручной ввод или генерация по seed)
- `3` — автотесты всех задач
- `4` — история запусков
- `5` — о программе
- `6` — настройки (тема, иконки меню, скорость анимаций, минимальная консоль)

## Настройки

Параметры лаунчера хранятся в `settings.json` рядом с exe (создаётся при первом запуске):

```json
{
  "Theme": "Classic",
  "IconStyle": "Emoji",
  "AnimationSpeed": "Normal",
  "Minimal": false
}
```

- **Theme** — `Classic`, `Hacker`, `Night`, `Sunset`, `Light`
- **IconStyle** — `Emoji` / `Strict` (строгие символы для conhost) / `Off`
- **AnimationSpeed** — `Normal` / `Slow` / `Off` (Esc прерывает анимации и отключает их до конца сессии)
- **Minimal** — минимальная консоль: без рамок, иконок и анимаций. Остаются только решения задач (`условие + ввод + шаги + ответ`), настройки и выход. Включается и выключается из настроек (`Настройки → Минимальная консоль`); по умолчанию выключено.

История запусков сохраняется в `history.json`.

## Минимальная консоль

Для сдачи проекта как «чистого» учебного решения есть режим минимальной консоли (`Minimal: true`):
меню сжимается до пунктов «Решения задач / Настройки / Выход», отсутствуют приветствие,
рамки, иконки и гистограммы, стартовая пауза и предупреждение. Логика решений не меняется —
скрывается только декоративное оформление. Вернуть обычный вид можно в любое время из настроек.

## Инсталлятор

Соберите `bin\Release` обоих проектов и скомпилируйте `installer/setup.iss` в [Inno Setup](https://jrsoftware.org/isinfo.php) (консольная компиляция: `ISCC.exe setup.iss`). Результат — `installer/setup.exe`.
